Before you paste a key

Use a key with a low spend limit, or a throwaway one you delete afterwards. Anthropic, OpenAI and Google all advise against putting API keys in a browser.

Your key goes from this browser straight to api.anthropic.com and nowhere else. The page keeps it in memory only: a reload forgets it, and it is never saved or logged.
