about your key

Your key goes from this browser straight to api.anthropic.com and nowhere else. The page holds it in memory only, so a reload forgets it. It is never saved or logged.

Anthropic, OpenAI and Google all advise against using API keys in a browser. Use a key with a low spend limit, or a throwaway one you delete afterwards.

Each request goes from your browser to this provider's API. No server of mine is involved.
