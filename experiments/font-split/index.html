Paste the @font-face rules from your stylesheet, or open your Google Fonts CSS link and copy what it returns. The tool reads each rule's unicode-range and never downloads the fonts.
The text your page shows, on as many lines as you need. Press Ctrl+Enter (⌘+Enter on a Mac) to inspect. Nothing leaves your browser.
result
Your rules describe more than one family, weight or style. The browser picks files for each face on its own, so choose the one your text is set in.

Hover a character to see which file draws it. A dotted underline means no rule covers it, so the browser falls back to the next font in the stack. The table lists the characters each file draws; hover a file name for its full URL.
